# AGENTS.md — OVERVODKA Agent Router

Этот файл — короткая точка входа. Он не должен дублировать все правила; его задача — быстро отправить агента в правильные документы.

## Что читать перед работой
Всегда в таком порядке:
1. `overvodka_agents/AGENTS.md`
2. `overvodka_agents/AGENT_RULES.md`
3. `overvodka_agents/AGENT_ONBOARDING.md`

Дальше по типу задачи:
- `overvodka_agents/LUA_HERO_EXPERT.md`
  Использовать для всего, что связано с героями, способностями, модификаторами, аспектами, талантами, предметами, `npc_heroes_custom`, `npc_abilities_custom`, `npc_items_custom`, тултипами и локализацией.
- `overvodka_agents/api_contract.json` и `overvodka_agents/endpoint_map.json`
  Читать только если задача реально затрагивает backend/API или `Server:SendRequest`.

## Базовая установка агента
- Сначала искать по репо, потом спрашивать пользователя.
- Предпочитать существующие паттерны этого проекта, а не абстрактные примеры из интернета.
- Делать минимальный дифф и не трогать чужие слои без необходимости.
- Не придумывать Dota API, KV-ключи, localization keys и структуру payload без проверки по репо.

## Что считается основной специализацией этого агента
- Lua-скрипты героев и предметов в `game/overvodka/scripts/vscripts`
- KV-файлы в `game/overvodka/scripts/npc`
- Локализация в `game/overvodka/resource`
- Связанный Panorama/UI-слой только если задача действительно пересекает отображение способности, предмета или героя
